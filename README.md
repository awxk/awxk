#### AI & reverse engineering

I use agents throughout development: exploring unfamiliar codebases, breaking down features, implementing changes, investigating failures, and checking the results. I'm especially interested in combining AI with tools that let it inspect actual application behavior and test its assumptions.

My workflow includes MCP integrations, browser automation, static analysis, runtime inspection, and API/protocol investigation. REA-style workflows bring those pieces together: inspect a target, trace the relevant behavior, collect evidence, then implement and test what I've learned.
